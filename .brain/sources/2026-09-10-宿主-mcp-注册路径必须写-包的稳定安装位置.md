# 来源：宿主 MCP 注册路径必须写"包的稳定安装位置", 不能写 ABS_DIR: A

## 记录（实时暂存，Teardown 时提炼进 concepts/ 后本页可删）
- 宿主 MCP 注册路径必须写"包的稳定安装位置", 不能写 ABS_DIR: ABS_DIR = install.js 自己住哪 —— 从仓库跑 abs install 就把仓库路径烧进宿主配置, 移包/卸全局即失效。且"已存在即跳过"的幂等分支会导致写错后永不修正(必须校对并校正)。判据: 用 dirname(process.execPath) 反查全局 node_modules, 取不到才回退 mcp,路径,安装,坑
