TITLE: 本地部署用 npm link 把全局包指向源码仓：改源码立即生效（四个宿主跟着走），代价是没有「已发布版本」这个回退点，且 npm i -g / abs update 会解除 link 装回 registry 版。方向是对的（源码即真源，与 deploy-artifact-copies 那条「别改 node_modules 副本」互补），但要记住 link 会被 update 解除。踩坑背景：本轮 1.7.9 精简看板为两区后，另一个 Cl​aude 窗口跑旧版 1.7.8 把 Topics/Backlog/Blocked 自动补建回来 —— checkBrainShape 分不清「用户手删」与「版本升级废弃」，双版本并存就互相拆台。教训：机械可判定 ≠ 语义上一定正确（同 Roadmap、话题树，同一错误犯三次）。
