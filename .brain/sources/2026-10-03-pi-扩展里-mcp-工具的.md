# 来源：pi 扩展里 MCP 工具的 tool_execution_end 事件 toolName 是**代理入口名**(实测 mcp__abs)…

TITLE: pi 扩展里 MCP 工具的 tool_execution_end 事件 toolName 是**代理入口名**(实测 mcp__abs), 不是子工具名(abs_task), 且该事件不带 args → 无法从它判断调的是哪个 MCP 工具。要识别具体子工具: 用 tool_call 事件(带 input, 子工具名在 input.tool 里)置标记, tool_execution_end 消费标记后刷新。另: pi 的 turn_end 不是'整轮回答结束'而是'每条 assistant 消息结束'(实测每条消息都触发, 约4秒一次) —— 拿它当兜底刷新已经够实时。
