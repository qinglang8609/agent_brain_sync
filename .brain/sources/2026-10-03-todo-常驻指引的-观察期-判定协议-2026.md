TITLE: todo 常驻指引的『观察期』判定协议(2026-10-03 起): 背景——abs todo 靠 agent 自觉登记, 实测不可靠(abs_task 调用 09-19 有38次/10-02 剩1次/10-03 为0)。修法是 pi 扩展 before_agent_start 往 system prompt 注入 3 条静态指引(动手前 start/完成立刻 done/断点及时 note), 已实测生效(hooks.log: todo_guide=on)。⚠ 但疗效未验证, 判定协议: ①必须在【开新会话干真任务】时观察, 不能在验证会话内自测(霍桑效应——注意力全在 todo 上会失真); ②用户别提 todo, agent 不知道自己被测; ③判据=干完一整个真任务后跑 abs todo, 有对应记录=机制有效, 记录为空=指引治不了需改走 tool_call 拦截(改文件时自动登记, 不依赖注意力); ④通过后动作: verify-todo-guide 标 done, prompt-guidelines-todo 发 1.9.10(⚠ 本机现为『官方1.9.9+手工同步的 hooks/abs.pi.ts』, 指引代码不在 npm 包里, 必须 npm install -g 覆盖 + abs install 重装才消除手工同步状态)
