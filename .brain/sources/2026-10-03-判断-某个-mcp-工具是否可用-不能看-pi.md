TITLE: 判断'某个 MCP 工具是否可用'不能看 pi 的工具注册表(两层都错): ① before_agent_start 的 event.systemPromptOptions.selectedTools 是基线值, 真实表要等 handler 之后(agent-session.js:1573)才回填 → 实测只有 31 个无关工具; ② 改用 pi.getActiveTools() 仍拿不到 —— MCP 默认 exposure=codemode, 工具本就不进 active 表(实测 mcp 工具输出 'lazy: tools from cache, not connected yet')。正解: 判断该项目能否用 abs, 直接查项目有没有 .brain/ 目录。教训: 同类假设连续两次都错, 说明'猜 API 语义'这个动作本身该被禁用 —— 查数据比查文档更可靠(目录存在与否是可直接观测的)。
