# 来源：排查 pi todo 面板「显示但缺任务」：真因不是面板 bug，而是 ~/.abs/config.json 的 user 被污染成 'audit'…

TITLE: 排查 pi todo 面板「显示但缺任务」：真因不是面板 bug，而是 ~/.abs/config.json 的 user 被污染成 'audit'。userConfigPath() 优先读 ABS_CONFIG_DIR、回退 homedir()，而 Node 的 homedir() 读系统真实用户目录、**不受 HOME 环境变量影响** —— 沙盒测试只设 HOME 时 config set 会写进真实 ~/.abs/config.json。面板按 user 过滤作者，非本人且非无作者的任务即不可见。
