TITLE: 定义了判据却没接到使用侧，比没判据更常见：abs query 排序混流水页的根因是 lint.js 早有 isTerminal 判据，但 query 排序没用它。教训是判据定义与使用要同 commit，否则两处各写一套、改了定义也不生效

## 记录
- 定义了判据却没接到使用侧，比没判据更常见：abs query 排序混流水页的根因是 lint.js 早有 isTerminal 判据，但 query 排序没用它。教训是判据定义与使用要同 commit，否则两处各写一套、改了定义也不生效

## 验证
- 实测：lint.js 第 215 行已有 `(pg.dir === 'sessions' && /^log-/.test(pg.slug))` 判据，但 query.js 排序处没用它，于是流水页压过内容页。修 query 时复用同一判据，问题即解。
- 同类：db.js 的 search/illuminate 曾各写一套排序口径，改了 search 没改 illuminate（注释自记「典型的改一半」）。
