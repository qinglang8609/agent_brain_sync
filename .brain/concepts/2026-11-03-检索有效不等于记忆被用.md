TITLE: 检索有效不等于记忆被用：主动取靠「触发规则写进 skill 开场」而非「工具更聪明」。实测一场会话 agent 全程没主动调检索，不是命令不够好，是没人告诉它「有疑惑那一刻该查」。修法两条配对：主动回忆（有疑惑就 recall）+ 主动提炼（sources 积压就 review/capture），判断力在 agent、落点在工具

## 记录
- 检索有效不等于记忆被用：主动取靠「触发规则写进 skill 开场」而非「工具更聪明」。实测一场会话 agent 全程没主动调检索，不是命令不够好，是没人告诉它「有疑惑那一刻该查」。修法两条配对：主动回忆（有疑惑就 recall）+ 主动提炼（sources 积压就 review/capture），判断力在 agent、落点在工具

## 验证
- 实测：开场加「你有知识库、随时能查」后，agent 遇到相关任务主动调了 recall；同查询「长期记忆 提炼 主动回忆」修前混 3 log 页 + 2 draft，修后纯 5 内容页（破坏验证：去掉隐藏逻辑测试即红）。
- 部署验证：`node bin/abs.js install --agent pi` 后 `grep -n 主动提炼 ~/.pi/agent/skills/abs-agent-brain-sync/SKILL.md` 命中。
