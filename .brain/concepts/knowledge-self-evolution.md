# 知识自我进化

「可自我成长的知识库」落到能验证的东西，只有一句：**能看出知识在往哪走，而不是只存不动。**

## 判据：什么叫「在进化」

| 信号 | 含义 | 不是坏事 |
|---|---|---|
| 有页被推翻并指向新页 | 知识在更新 | 推翻数 > 0 是好事，说明有人回头修正 |
| 标了推翻却没指向 | 历史断了 | 报错，看不出被谁取代 |
| 同一主题堆了很多页 | 该合并成规律页 | 堆到 8 页以上提出来 |
| 只被链、不链别人 | 是终点不回连 | 若它其实是枢纽，该补出链 |
| 长期没动且无人链 | 可能该删 | 90 天阈值 |

**执行：`abs db evolve`。** 只体检，不改任何东西 —— 改不改是内容决策。

## 关键实现：推翻关系必须进库

原状态：`superseded-by` 只写在 markdown 的一行 frontmatter 里，库里只存 `status` 不存走向。
于是「进化」在检索侧完全看不见 —— 库能说「这页被推翻了」，说不出「被什么取代了」。

现在 `nodes.superseded_by` 存这个关系，进化体检才能追踪链条。

## 三个实测踩出来的判据错误

**一，类型标签不是主题。** `tags` 第一项是页面类型（concept/source/session-log），
拿它归类必然把 58 页 concept 报成「一组堆积」。类型词按白名单跳过，主题看第二项起。

**二，会话流水不该报堆积。** `sessions/` 下的归档快照带 `todo-archive` 标签，
按主题归类会把 13 个快照报成「该合并」—— 但它们本来就该各自独立（一天一文件是目录契约）。判据看 `dir`。

**三，入口过滤了，出口没过滤。** `search` 里排除了 superseded，但 `illuminate` 的扩散出口没排 ——
旧结论页自己不进种子，却被邻居点亮（实测亮度 0.24 带 `↝` 标记）。
等于绕过了「被推翻的经验别再依据」这条铁律。凡是「不该出现」的过滤，要检查所有产出路径，不只是入口。

## 验证

```bash
abs db evolve          # 进化体检
node --test test/evolve.test.js   # 7 个判据测试
```

真实场景验证（2026-11-02）：
1. 建两页（旧结论 / 新结论），执行 `abs supersede old --by new`
2. `abs db evolve` 报 `✓ 已推翻 1 页  old-truth → new-truth`
3. 检索旧结论的独有关键词，旧页完全不出现（含扩散路径）
