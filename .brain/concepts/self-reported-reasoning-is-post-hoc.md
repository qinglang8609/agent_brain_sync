# 让模型自述思考层 ≠ 真思考：实测是「知答案后编陪跑」

## 触发场景
想给 AI 加一层「先想清楚再答」的机制：要求它输出推理骨架（分层思考、先列假设、给判断轴），
或想用「它写了推理过程」当**可信度信号**。

## ❌ 表现
`skill/abs-think-tree` 实现了三层骨架（L1 为什么问 → L2 边界在哪 → L3 要什么），
机制看着很硬：下坠 + 兄弟竞争、裁判是父节点（外部给定）、一次 forward pass 完成。

**实测把它否了**：L1 的答案 **8/8 都落在第 1 位** ——
候选之间根本没有真实竞争，模型是**先知道答案，再编出一串陪跑候选**。
「看起来像思考过程」的产物，其信息量 ≈ 0。

→ 结论：把「输出推理层」当作质量保证是**假链条**；自述推理是事后合理化，不是思考本身。

## 🛠 解法
1. **判据看盲测命中率/消融，不看产物形态**：要证明思考层有用，得能指出
   「去掉它 → 结果变差」的**具体差值**（如候选排序被打乱、答案偏离）。
   8/8 首位 = 没有竞争 = 没有信息 = 该删。
2. **该删就删，并把 knowledge 一起收**：本次直接删掉 `skill/abs-think-tree`
   （含 check.js 与测试纳入），不留「以后可能有用」的孤儿设计。
3. 剩下的耐久部分才进图谱（本页）。设计细节（L2 三轴、停止规则）随 skill 一起废 —— 
   **不要为已删除的产物保留 active 概念页**，那会让下个会话照着一个不存在的机制干活。
4. 反过来说：真正有用的推理辅助是**外部约束**（校验器、测试、真实数据回灌），
   不是让模型多写几段话。

## 验证
删除依据是用户实测试数：L1 候选 8/8 落第 1 位（无真实竞争）= 假思考过程。
`grep -rn "think-tree"` 全仓无残留引用；`git log -- skill/abs-think-tree` 显示
`00f220f v1.8.8 新增` → `9df304b v1.8.9 删除`，进出都有记录。
（本页只保留「实测否证」这个结论，不含被推翻的设计细节。）
