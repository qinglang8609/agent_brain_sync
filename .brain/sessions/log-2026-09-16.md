# 会话 2026-09-16 — 修 `abs serve` 端口写死

## 一、起因

用户报：**「7777 端口太固定，这个项目开 7777，另外一个项目就开不了了」**

## 二、定位（一处根因，两处默认值）

`grep -rn 7777` 全仓命中 3 处，其中 2 处是**真默认值**，1 处是文档：

| 位置 | 原值 | 性质 |
|---|---|---|
| `bin/abs.js:377` | `opts.port ? Number(opts.port) : 7777` | 真默认值 |
| `src/serve.js:465` | `serve({ port = 7777 })` | 真默认值 |
| `bin/abs.js:195` | 帮助文本 `[--port 7777]` | 文档 |

**根因**：默认值是个固定端口，进程间无协调 → 第二个项目 `EADDRINUSE`。

## 三、解法：默认 0，让 OS 分配

```js
const port = opts.port ? Number(opts.port) : 0;   // bin/abs.js
export async function serve({ root, port = 0, host = '127.0.0.1' })   // src/serve.js
```

**为什么这样就够**（不是"顺便"）：`serve()` 本来就返回 `server.address().port`
（真实端口），调用方 `bin/abs.js` 用的是 `url` 而非 `port` 变量 → **调用链无需任何改动**，
打印和 `open` 自动指向正确地址。

## 四、验证（真跑，非推断）
