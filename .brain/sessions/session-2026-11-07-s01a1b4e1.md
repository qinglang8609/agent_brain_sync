# 会话：还原输入框左下角昵称到面板标题

> 2026-11-07 · 技术类 · 用户发言 2 句 · 工具调用 43 次

## 出了什么问题
<!-- 具体症状 / 报错 / 复现条件 -->
- 1.28.0 把「作者名·昵称」从 todo 面板标题搬到输入框左下角，用户实测难看，要求还原。
- 切模型时输入框上边框的模型名不刷新：扩展监听的 model_changed 事件在 pi 里不存在（实际是 model_select），刷新从未触发。

## 怎么解决的
<!-- 根因 + 改了哪里 -->
- 面板标题恢复为 `Todo (n) — fanchao·昵称`（abs.pi.ts / abs.omp.ts 的 renderPanelLines），输入框左下角标签删除：abs-rounded-editor/index.ts 里 readUser/pickNickname 搬运逻辑整段删掉，roundBorder 的 leftLabel 参数保留备用，顺带清理三个不再用的 import。
- 模型名刷新监听改回 model_select（修复切模型不刷新）。
- 三份副本同步：node bin/abs.js install --agent pi / omp --yes，安装副本与当前模板渲染结果一致（差异仅占位符替换与托管标记注释）。

## 验证什么命令
<!-- 跑什么确认已修好 -->
- npm test → 817 全绿；npm run check → 语法+eslint 通过。
- 安装副本核对：diff hooks/abs-rounded-editor/index.ts ~/.pi/agent/extensions/abs-rounded-editor/index.ts → 一致；abs.ts 比对模板渲染结果 → 一致。
