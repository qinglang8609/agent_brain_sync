# 会话：会话页机制落地 + 七轮判据修正

> 2026-11-05 · 技术类 · 用户发言 10 句 · 工具调用 320 次

## 出了什么问题
起点是一句诉求：**abs 只沉淀编程经验与教训，要它成为大型知识图谱，就必须把会话本身也整理进图谱。**

顺着做下去，每往前一步都露出一层新问题（七轮）：

1. 会话内容**没有落点** —— 所有写入管道都压成「触发场景/❌表现/🛠解法」，发言、决策、业务操作无处可去
2. 落点做出来后仍然**被动** —— 等 agent 想起来调，而「靠提醒养成习惯」本仓已被实测否证两次
3. 改成机械触发后**空骨架页污染检索** —— 419 场会落页，20 张空页就能把真知识页挤出结果
4. 同日多场会话**只落一场就把其余埋掉**（真实有 14 天是多会话日，最多一天 10 场）
5. 落页不记账，`summon`**永远催已落页的会话**
6. 同时开两个会话时**落错页**（`--last` 按 mtime 猜）
7. 摘要抓的是**没说完的半句**（本页标题原来是「…，我/」）

## 怎么解决的
**一、会话页（`abs ingest`）**：按「改过什么文件」机械判三种形状 —— 技术类（问题/解法/验证）、
业务操作类（做了什么/结果/注意）、讨论类（谈成了什么/没结论的地方）。只给骨架和素材，不写结论。
与会话双向挂钩：frontmatter 记 `session`/`session-file`/`project`，文件名带 id 前 8 位。

**二、机械触发**：挂在 `session_shutdown`，不往对话插话（那条路 2026-09-18/10-05 两次被否）。
判据只收真改过文件的会话。传本会话 id（`--session`）而非 `--last`，多会话才不落错。

**三、未填页三层防护**：入库算 `unfilled` 列 → 种子排除 → **扩散出口也排除**
（入口排了出口不排，会从邻居 `↝` 绕回来）。已填的才参与并享 0.5 降权。
`load` 顶部列未填张数，按日期倒序，最多 5 个。

**四、判据对齐**：单场会话页不算「整天快照」（否则同日其余会话被埋）；
落页即记账（判据从「人读过没」改成「有没有对应的页」）。

**五、命令面精简**：`capture --layer 5/7` 改拒（落点违规/与 note 重复）、
MCP 删 `abs_board`（被 load 覆盖）与 `abs_wrapup`（hook 内部命令），13→11。

## 验证什么命令
```bash
npm test                          # 787 全绿
node bin/abs.js db search <词>    # 未填页不出现；已填页亮度约半
node bin/abs.js summon            # 只列没落页的
node bin/abs.js load              # 顶部列未填会话页
```
破坏验证若干：撤掉 prev 迁移 → 2 条红；撤掉 hook 传 sid → 1 条红；
去掉空骨架排除 → 知识页被空页挤掉（实测前 12 名全空页）。
