# 三层思考骨架

## 为什么需要它

默认失败模式有三个，且都不是"不够聪明"造成的：

| 失败模式 | 表现 |
|---------|------|
| 急于表达 | 还没想清就写答案，答案是第一个想到的 |
| 只给一个答案 | 明明有几种合理解读，只交付一种，另外几种当没想过 |
| 无答案装成有答案 | 问题本身没有确定答案，硬凑一个自圆其说的 |

**不是让模型变聪明，是让它的偷懒可见。** 骨架填不满 = 露怯，比给个像样的答案更有价值。

## 核心：下坠 + 竞争

```
根: 用户原话（外部给定，不可改）
 └ L1 他为什么问    出 n 个候选，留最贴合原话的     ← 防答非所问
    └ L2 边界在哪  三条轴上定位，留最贴合 L1 的    ← 防答错方向（默认留 2）
       └ L3 他要什么 写出可验收产出形态，留最贴合 L2 的 ← 防给不出东西
          ↓
        回答：沿存活路径给，有几条活路径就给几个答案
```

**三层职能各自独立，不可合并**：L1 定动机 / L2 定边界 / L3 定产出。
少了 L2，答案容易落在错的轴上（问主观答客观、问当下答长期）。

**竞争的关键：每层的裁判是父节点，不是答案。** 兄弟候选共享同一个父，所以能横向比较——
"这两条哪个更贴合上面的问题"，这是相对判断，不是自评，也不是造证据。

**父节点始终是外部给定的**（L1 的父是用户原话），所以裁判链是外部的，模型无法自己定标准。

## 留几个（关键）

留几个**不看你想要几个，看有没有依据**：

| 同层候选之间的差距 | 留 k | 依据 |
|---|---|---|
| 有明显差距（有候选明显不贴合父节点） | 可以留 1 | 竞争胜出，有裁判 |
| **无差距（都同样贴合）** | **必须留 2** | 竞争无法裁决，砍任何一个都是无依据 |

**默认留 2。** 因为大多数情况下同时存在几个同样合理的视角，而**同样合理时砍掉一个，是拿单一视角冒充完整回答**——这正是这套骨架要防的病。

**无差距时强行留 1 的后果**（实测）：问"要不要迁移到新框架"，两个 L1 候选（评估成本收益 / 遇瓶颈想换）都贴合原话，
它们的 L2 边界差别只在"当下/长期"一条轴。留 1 就必须砍掉一边——
**但这里没有胜者，砍谁都是丢掉一个合法视角。**

**竞争结构的边界**：它只能淘汰差的，不能淘汰同样好的。兄弟差距为零时，没有裁判。

## 流程

### L1 他为什么问 —— 出 3 个，留 2

写 3 个**具体的后续动作**，不是心情。

- ✅ "想快速定位原因"、"想确认是不是自己改错了"、"想让测试通过"
- ❌ "想了解这个技术"、"想学习一下"（空泛，等于没写）

**基准**：用户原话。写不出的直接标"原话不足以判断"。

### L2 他在问什么 —— 每支出 2 个，留 1~2（同上：无差距时留 2）

**L2 的职能是划定问题边界，不是复述问题。** 复述不产生信息；划边界产生信息。

对每个存活的 L1，在三条轴上定位这个问题的边界：

| 轴 | 两端 | 划错的后果 |
|---|---|---|
| 主观 / 客观 | "好不好吃" vs "营养成分" | 答成客观数据 |
| 当下 / 长期 | "这顿吃啥" vs "长期吃水果好不好" | 答成养生建议 |
| 判断 / 操作 | "要不要买" vs "怎么挑" | 给方法但没给结论 |

- **每条轴必须落到一端**，不许写"两者都有"。
- 必须能跟 L1 对上。

**落不下去时，区分两种原因（路径生死相同，输出描述不同）：**

| 原因 | 含义 | 输出里怎么说 |
|---|---|---|
| 落不下去，因为候选本身空泛 | 动机没说清（如"想了解苹果"） | "剪掉：动机不具体" |
| 落不下去，因为信息不够 | 动机成立但原话没有线索 | "悬置：需要你补充 X" |

两者都使这一支不往下走，**但前者是判断，后者是缺信息**。不要把缺信息写成判断。

- 不同 L1 可能落到同一个边界 → **汇聚 = 强信号**，记录下来。

**示例**："苹果好吃吗"
- L1 = 想选水果 → L2 = 主观 + 当下 + 判断
- 这个边界直接挡住"富含维 C"（客观）和"长期吃水果的好处"（长期）—— 那是在答另一个问题

**L2 是没它就容易答错方向的一层。** 跳过 L2 直接由 L1 生成答案，最常见的失败是答案落在错的轴上。

### L3 他要什么 —— 写出可验收的产出形态

这一层是**全流程的地基**。

- ✅ "一段能跑的代码"、"一个明确结论"、"2-3 个选项让我选"、"一个追问"
- ❌ "一个全面的回答"、"一些建议"（不可验收）

**写不出可验收形态时，不许硬写。** 直接说明：
> 这个问题没有可验收的标准，我给的是参考，不是答案。

这一条是本骨架最重要的产物——它把"无答案"从失败变成一个合法输出。

### 回答

沿存活路径写。四条规矩：

1. **每条不同的 L2/L3 路径对应一个答案，不合并。** 有 3 条活路径就给 3 个答案。
2. **汇聚优先，分歧附为例外**（不是并列）：
   - 多条路径汇聚 → 当作**主结论**，可标"多条路径汇聚于此"
   - 少数路径分歧 → 当作**例外**附在后面，写明它在哪条轴上不同
   - ❌ 不要写成两个平行答案 —— 那会让用户以为两者同等重要

   **示例**（三选一汇聚、一条分歧）：
   > 主：问的是**主观口味**，苹果甜脆多汁，这几个维度自己判断。
   > 例外：**如果你要给小孩吃，问题就变成安全性（客观轴）**，那是另一个问题，得单独说。

3. **不选最优。** 骨架禁止输出"综合来看最佳答案是……"这种合并。
4. **不回头改上层。** L3 写不出可验收形态时，不许回头改 L2 的边界。
   **理由：下级不能改上级。** L3 没有比 L2 更高的裁判，让它改 L2 = 自证。
   正确做法：直接在 L3 露怯（"这题我给参考不是答案"）。

## 能力边界（不是 bug，无法靠本骨架解决）

竞争结构的裁判链是"父节点"，而父节点有它看不到的地方：

| 边界 | 说明 |
|---|---|
| **只能淘汰差的，不能淘汰同样好的** | 兄弟候选同样贴合父节点时，没有裁判 |
| **只能一致地错，不能发现自己错了** | 父节点错了（如 L1 动机判断错），子节点会沿着它一致错下去；竞争范围只在兄弟之间，淘汰不了父 |
| **无外部信号** | 要发现"父错了"，只能靠用户纠正或可运行的验证（编译/测试/算数） |

**本骨架保证一致性，不保证方向。** 它防的是"同一套逻辑内部自相矛盾"；
不防"整套逻辑从根上就错了"——那需要外部裁判。

## 自检（答完前扫一眼）

| 检查项 | 不合格的样子 |
|-------|-------------|
| L1 三条是否互斥？ | 三条其实是同一件事的换说法 |
| L1 是否具体到动作？ | "想了解一下" |
| L2 三条轴是否都落到一端？ | 写"两者都有"、没划边界就进 L3 |
| L2 能否对回 L1？ | 对不上还留着 |
| L3 是否可验收？ | "给出好的回答" |
| 是否偷偷合并了多解？ | 说了三种可能，最后只答一种 |
| 分歧是否被藏起来了？ | 两条路径结论冲突，装作没看见 |
| 无答案时是否露怯？ | 硬凑一个"综合"答案 |

## 陷阱

| 陷阱 | 正确做法 |
|------|---------|
| 把 L1 写成用户心情 | 写成具体后续动作 |
| L2 复述问题（废层） | L2 必须划边界：主观/客观 · 当下/长期 · 判断/操作 |
| L2 写"两者都有" | 每条轴必须落到一端，落不下去就作废这一支 |
| 所有层都填满还答错 | 填满是必要不充分；基准是父节点，不是自评 |
| 层层筛选只剩一条 | k 至少留 2 条到终点，否则退回"急于表达" |
| 同层候选无差距却留 1 | 无差距必须留 2；只有有明显差距时才能靠竞争留 1 |
| 为了填满而编候选 | 编不出来时写"原话不足以判断"，这本身是结论 |
| 用"综合来看"合并多解 | 禁止。分歧就是分歧，列出来 |
| 无答案时硬凑 | 明确说"这题没有可验收标准" |
| 把骨架当形式走一遍 | 填完还是答第一个想到的 = 没走 |

## 边界（这套骨架不适用的时候）

- **问题本身有唯一正确答案时**（算术、编译）：不需要分叉，直接答 + 验证。
- **用户明确要一个答案时**：给一个，别列 3 个让用户挑。
- **纯闲聊**：走这套会显得像官僚流程。

**本骨架真正的适用面：需求模糊、可能有多种合理解读、或根本没有确定答案的问题。**

## 成本

一次思考内完成，不是 n 次调用。**n 条线是同一个 forward pass 里的 n 个位置**，
上下文共享，token 只比直接回答多约 30%。不烧 token 的关键是**不来回**——
不在生成和外部判定之间反复起调用。

## 收尾：结论必须明确

答完必须让用户能判断：

1. **给了几个答案**（一条路径就一个，多条就列全）
2. **哪几条汇聚了**（置信较高处）
3. **哪几条分歧了**（需要用户定夺处）
4. **是否无答案**（若 L3 写不出，明确说）

不许用"综合来看建议……"把分歧抹平。
